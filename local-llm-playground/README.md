# Local LLM Playground

Run open-source LLMs locally instead of relying on hosted APIs, and compare
their behavior/performance to hosted models.

## Goals
- Run at least one open-source model locally (e.g. via Ollama or llama.cpp).
- Compare response quality, latency, and resource usage vs. a hosted model.
- Experiment with quantized models to see the quality/speed tradeoff.

## Possible Tech Stack
- Ollama, llama.cpp, or LM Studio for local model hosting
- Open models such as Llama, Mistral, or Phi

## Getting Started
- [ ] Install a local model runner and pull a small model
- [ ] Write a simple script/CLI that sends prompts to the local model
- [ ] Record notes comparing local vs. hosted model responses
