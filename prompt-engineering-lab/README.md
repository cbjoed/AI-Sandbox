# Prompt Engineering Lab

A space for systematically testing prompts, comparing techniques (few-shot,
chain-of-thought, structured output), and tracking what works best.

## Goals
- Build a small harness that runs the same prompt across model/temperature
  variations and records the outputs.
- Compare zero-shot vs. few-shot vs. chain-of-thought prompting on a task.
- Keep a log of prompt variants and their observed strengths/weaknesses.

## Possible Tech Stack
- Python script(s) or notebook for running prompt variations
- Any LLM API (hosted or local)

## Getting Started
- [ ] Choose a benchmark task (classification, extraction, Q&A, etc.)
- [ ] Write 2-3 prompt variants for that task
- [ ] Run each variant and record accuracy/quality notes
- [ ] Summarize findings in this README
