# Multimodal Assistant

Experiment with an assistant that can handle more than just text, such as
images, audio, or a combination of inputs.

## Goals
- Accept an image (and optionally text) as input and get a useful response.
- Explore basic use cases: image captioning, visual Q&A, or OCR + summarization.
- Note the limitations/quirks discovered while testing multimodal inputs.

## Possible Tech Stack
- A multimodal model API (e.g. GPT-4 Vision, Claude with vision, Gemini)
- Optional local multimodal models for offline experiments

## Getting Started
- [ ] Pick a first multimodal use case to try (e.g. "describe this image")
- [ ] Wire up a simple script that sends an image + prompt to the model
- [ ] Test with a handful of varied images and record results
