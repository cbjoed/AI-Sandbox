# AI-Sandbox

A sandbox for trying out different AI project setups. Each idea lives in its
own folder with a README describing the goal, a possible tech stack, and a
getting-started checklist.

## Project Ideas

- [`rag-pipeline/`](rag-pipeline/README.md) - Recreate a Retrieval-Augmented
  Generation (RAG) setup: ingest docs, embed/store them, and answer questions
  using retrieved context.
- [`agentic-workflows/`](agentic-workflows/README.md) - LLM agents that plan,
  call tools, and act in a loop to complete multi-step tasks.
- [`local-llm-playground/`](local-llm-playground/README.md) - Run open-source
  LLMs locally and compare them to hosted models.
- [`fine-tuning-experiments/`](fine-tuning-experiments/README.md) - Fine-tune
  a small model on a custom dataset and evaluate the results.
- [`prompt-engineering-lab/`](prompt-engineering-lab/README.md) - Test and
  compare prompting techniques on a benchmark task.
- [`multimodal-assistant/`](multimodal-assistant/README.md) - Experiment with
  assistants that handle images/audio alongside text.

Add a new folder per idea as new setups are explored.
